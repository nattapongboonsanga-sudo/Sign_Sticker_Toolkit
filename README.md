ชุดโปรแกรมงานป้าย & สติ๊กเกอร์ (Sign & Sticker Toolkit)

คำอธิบายสั้น (สำหรับใส่หน้าเว็บ/โพสต์)
รวม 3 เครื่องมือสำหรับร้านป้าย สติ๊กเกอร์ และงาน CNC ไว้ในที่เดียว ใช้งานผ่านเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งโปรแกรม ล็อกอินครั้งเดียวก็เปิดใช้ได้ทั้งหมด รองรับภาษาไทยและอังกฤษ

คำอธิบายเต็ม

ชุดโปรแกรมนี้สร้างโดย MOS DESIGN เพื่อช่วยลดงานคำนวณและงานจัดวางที่ต้องทำซ้ำทุกวันในร้านป้ายและโรงงาน คุณเลือกโปรแกรมจากหน้าแรกแล้วสลับไปมาระหว่างเครื่องมือได้จากแถบด้านบน มี 3 โปรแกรมดังนี้

1. CNC Nesting Studio Pro
ระบบจัดวางชิ้นงานบนแผ่นวัสดุอัตโนมัติ เพื่อประหยัดวัสดุและสร้างไฟล์สั่งตัด

นำเข้าไฟล์ DXF และ Adobe Illustrator (.AI / .AIT / .EPS) ได้ทุกเวอร์ชัน
ตั้งค่าแผ่นวัสดุ ระยะห่างชิ้นงาน ขอบแผ่น และองศาการหมุนได้ ตั้งแต่ไม่หมุนจนถึงหมุนอิสระหรือหามุมที่ประหยัดสุดอัตโนมัติ
มีตัวเลือกขั้นสูง เช่น แบ่งตามสี พลิกกระจก ดันชิ้นงานชิดมุม และให้ระบบลองหลายรูปแบบเพื่อหาผลที่ประหยัดที่สุด
มีเส้นตัดแยกเศษ และตัดแผ่นเศษใหญ่เก็บไว้ใช้ต่อ
สร้าง G-code สำหรับเครื่อง CNC Router, Mill, Plasma, Oxy-fuel และ Laser มีฐานข้อมูลดอก/หัวตัด รองรับ Profiling, Engraving, Pocket และ Drilling มี Tabs, Lead-in/out และลำดับการตัดที่คำนวณเส้นทางสั้นสุดให้
ดูตัวอย่างการวิ่งของหัวตัดก่อนส่งออก และส่งออกได้เป็น G-code, DXF, AI, PDF, EPS และ SVG พร้อมแยกเลเยอร์

2. คำนวณเรียงสติ๊กเกอร์ต่อแผ่น

ใส่ขนาดแผ่น (A4, A3, A5, A3+, 9×12 นิ้ว หรือกำหนดเอง) และขนาดสติ๊กเกอร์ ระบบบอกว่า 1 แผ่นได้กี่ชิ้น พร้อมผังการวาง
รองรับรูปสี่เหลี่ยม มุมมน วงกลม และวงรี ลองหมุน 90° และเรียงสลับฟันปลาเพื่อให้ได้จำนวนมากที่สุด
คิดราคาขายแบบขั้นบันไดตามจำนวนแผ่น แก้ไขราคาได้เอง และจำค่าที่ตั้งไว้ในเครื่อง

3. คำนวณวัสดุป้ายไวนิล / สติ๊กเกอร์

ใส่ขนาดงานและจำนวน ระบบคำนวณว่าต้องใช้ไวนิลหรือสติ๊กเกอร์กี่ม้วน และฟิวเจอร์บอร์ดกี่แผ่น
เพิ่มได้หลายงานในรอบเดียว รองรับหน่วย ซม. เมตร นิ้ว ฟุต
ตั้งค่าเว้นขอบ ระยะห่าง และเผื่อเสียได้ แก้ชื่อ ขนาด และราคาวัสดุได้ และโหมดอัตโนมัติจะเลือกวัสดุที่ถูกที่สุดให้
แสดงตัวอย่างการวางงานบนวัสดุ

จุดเด่น

ใช้งานผ่านเบราว์เซอร์ ทำงานบนอุปกรณ์ของผู้ใช้ ไฟล์งานที่นำเข้าไม่ได้ถูกอัปโหลดไปที่เซิร์ฟเวอร์
ใช้ได้ทั้งคอมพิวเตอร์และมือถือ
ระบบล็อกอินด้วยอีเมลหรือ Google (Firebase)
หน้าตาเดียวกัน สลับไทย/อังกฤษได้ทันที
